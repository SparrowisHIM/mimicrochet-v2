Fonts for the share pictures (`components/share/share-card.tsx`). All are SIL Open Font License 1.1.

- `YoungSerif-Regular.ttf`: Young Serif (google/fonts, ofl/youngserif), Latin subset.
- `Figtree-Medium.ttf`, `Figtree-SemiBold.ttf`: Figtree (google/fonts, ofl/figtree), static 500 and 600 cuts, Latin subset.
- `Inter-Naira.ttf`: Inter, static 500, only the ₦ sign, digits, comma and space. Young Serif and Figtree have no ₦.
